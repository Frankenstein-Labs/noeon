# Catalog

- `sources.toml` — audited allowlist. `mode = "import"` copies content into the
  registry; `mode = "reference"` only records how many `SKILL.md` files exist and
  why the content is not imported (licence, aggregation, provenance).
- `sources.lock.json` — generated by `noeon-skills sync`: resolved commit per
  source and the real counters (discovered / imported / validated / blocked /
  review / skipped).
- `registry.jsonl.gz` — generated locally, git-ignored index: one JSON object per
  imported skill with its content hash, licence, source commit, category,
  permissions and security findings. `sources.lock.json` records its SHA-256 and
  size, so the pinned state is verifiable without shipping third-party rows.

First-party skills live in `core/` and are imported locally:

```bash
python -m noeon.skills.cli import-local catalog/core \
  --repository noeon/core --license proprietary
```

Refresh after a source change:

```bash
python -m noeon.skills.cli sync --registry .noeon/skills.sqlite3 \
  --cache .noeon/cache --lock catalog/sources.lock.json \
  --export catalog/registry.jsonl.gz
python -m noeon.skills.cli import-local catalog/core \
  --repository noeon/core --license proprietary
```

Load the generated index without network access:

```bash
python -m noeon.skills.cli load catalog/registry.jsonl.gz
```

Imported records store no content; `install` fetches it at the pinned commit.
Records from `core/` keep a repository-relative `local_path`, so re-run
`import-local` after moving the repository.

Refs are pinned to the commits recorded in `sources.lock.json`; bumping a source
is a deliberate edit that produces a new lock and a new registry hash. Installs
verify the stored SHA-256 and refuse content that changed upstream.

The skill files themselves are intentionally not committed: `sync` and `install`
fetch them at the pinned commit into `.noeon/cache` and `.noeon/skills` (both
git-ignored). This keeps third-party content and its licence obligations out of
this repository while preserving verifiability.
